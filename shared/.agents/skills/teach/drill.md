# Drill

Practice on known material. Difficulty is the tool here.

1. Set one problem. Withhold the solution. Done when the user has attempted.
2. Ask calibration, grade, reveal, enter in the ledger (`thread.md`, Ledger). Done when the item has a ledger row.
3. Escalate difficulty on success; one near-transfer variant before moving on (`thread.md`, step 4). Once two or more concepts are in play, **interleave** them.

Multiple choice: every option the same word count; the correct option is never the only fully reasoned one; vary its position deliberately, and in any rendered quiz shuffle at render time.

Exit: `thread.md`, Exit criterion.
